# Лабораторные работы по программированию (C# WPF)

Десктопное приложение для проведения и визуализации лабораторных работ.

## Лабораторная работа №4: «Алгоритмы сортировки данных»
Исследование и одновременное сравнительное тестирование алгоритмов сортировки с динамической графической визуализацией.

### Реализованные возможности
- **Выбор лабораторных работ**: главное меню с карточками работ (№1–№5) и выпадающим списком.
- **Алгоритмы сортировки**:
  1. Пузырьковая сортировка ($n - 1$)
  2. Шейкерная (двунаправленная) сортировка ($\frac{n - 1}{2}$)
  3. Сортировка вставками
  4. Быстрая сортировка (Quick Sort)
  5. BOGO сортировка (со случайным перемешиванием и настраиваемым лимитом итераций)
- **Одновременная визуализация**: синхронное пошаговое отображение сортировки на отдельных графических дорожках (столбчатые диаграммы с цветовой подсветкой сравнений и обменов).
- **Сводная таблица результатов**: замер точного времени ($t$ в мс/мкс через высокоточный `Stopwatch`) и количества итераций ($к/и$) с автоматическим определением и выделением самого быстрого алгоритма.
- **Ввод данных**:
  - `DataGrid` (до 50 элементов) с возможностью ручного редактирования.
  - Генератор случайного массива в диапазоне $[A, B]$.
  - Импорт из файлов **Excel** (`.xlsx`, `.csv`).
  - Импорт из **Google Таблиц** (по ссылке или вставкой из буфера).
- **Тумблер направления**: по возрастанию / по убыванию.
- **Меню взаимодействия (`MenuStrip`)**: Файл, Действия, Справка.
- **Отказоустойчивость**: валидация входных значений и уведомление о некорректных данных.

## Требования для сборки и запуска
- **ОС**: Windows 10 / 11 (64-bit)
- **.NET SDK**: .NET 10 (или запуск автономной сборки `Self-Contained`, не требующей установленного .NET).
- **Среда разработки**: Visual Studio 2022 / Rider / VS Code.

## Запуск
```powershell
# Сборка и запуск через dotnet CLI:
dotnet run --project LabWorksApp/LabWorksApp.csproj

# Запуск тестов:
dotnet test LabWorksApp.Tests/LabWorksApp.Tests.csproj
```
